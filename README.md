# CodexDesk 2

แอป Electron สำหรับใช้งาน Codex CLI กับโปรเจกต์ในเครื่อง

## ดาวน์โหลด

ดาวน์โหลด Setup เวอร์ชันล่าสุดจาก https://github.com/nidvjj-sudo/CodexDesk/releases/latest

## ติดตั้ง

1. ติดตั้ง Node.js LTS x64
2. เปิด `build.cmd`
3. เปิด `CodexDesk-Setup-2.9.0-x64.exe` ในโฟลเดอร์ `release`
4. กดปุ่มเข้าสู่ระบบภายใน CodexDesk

## พัฒนา

```cmd
npm install
npm run dev
```

## ระบบ

- Electron และ React
- Monaco Editor
- Motion spring animation
- Codex CLI
- เข้าสู่ระบบ ChatGPT ผ่านเบราว์เซอร์เป็นค่าเริ่มต้น และมี Device Code เป็นวิธีสำรอง
- ปุ่มสถานะการเชื่อมต่อ ChatGPT บนแถบด้านบน
- ไม่มีหน้าต่าง CMD ระหว่างใช้งาน
- เรียก Codex แบบ Native background process และปิด stdin อัตโนมัติ
- ตรวจสอบ Codex runtime ก่อนสร้างแอป
- ปิดโปรเซส Codex ทั้งหมดเมื่อหยุดงานหรือปิดแอป
- ใช้ CODEX_HOME แยกจาก Codex ตัวอื่นเพื่อป้องกันแคชชนกัน
- แชต Codex มี Scrollbar และเลื่อนไปข้อความล่าสุดอัตโนมัติ
- ลบรหัสสี ANSI ออกจากลิงก์และข้อความทั้งหมด
- ไม่มี Terminal ในหน้าหลัก ใช้งานผ่านแชต Codex เท่านั้น
- โหมดแก้ไขไฟล์รองรับ Windows Server 2019 โดยไม่เรียก PowerShell
- ซ่อน diagnostic log ภายในและแสดงเฉพาะคำตอบของ Codex
- รองรับโฟลเดอร์ที่ไม่ได้เปิดใช้ Git
- ตรวจ GitHub Releases อัตโนมัติและมีปุ่มดาวน์โหลดกับติดตั้งอัปเดตในแอป
- ไม่ดาวน์โหลดหรือติดตั้งอัปเดตเอง ต้องกดยืนยันจากปุ่มอัปเดตเท่านั้น
- รองรับคิวข้อความระหว่าง Codex กำลังทำงาน
- กด Ctrl ซ้าย + O เพื่อดูคำสั่ง กิจกรรม และคิวงาน
- แสดงข้อความแบบ Markdown และ GitHub Flavored Markdown
- กดลิงก์ไฟล์ในแชทเพื่อเปิด Editor และเลื่อนไปยังบรรทัดที่ระบุ
- หน้าหลักแบบ ChatGPT มีเมนูและประวัติด้านซ้าย แชทตรงกลาง และ Artifact panel ด้านขวา
- Code box และ Text box เปิดอัตโนมัติจากคำตอบ รวมถึงไฟล์ที่ Codex เพิ่งสร้างหรือแก้ไข
- แนบรูปและวิดีโอในแชท โดยวิดีโอจะถูกอ่านผ่านเฟรมตัวอย่าง
- จำประวัติแชทและบริบท Codex แยกตามโฟลเดอร์โปรเจกต์
- สร้างแชทใหม่และสลับกลับไปดูประวัติหลายบทสนทนาในแต่ละโฟลเดอร์ได้
- Responsive UI สลับมุมมองไฟล์ โค้ด และแชทอัตโนมัติตามขนาดหน้าต่าง
- โหมดถามยืนยันก่อนให้ Codex แก้ไขไฟล์หรือรันคำสั่ง
- Live Activity แสดงงานปัจจุบัน ไฟล์ที่แก้ และจำนวนบรรทัดเพิ่มหรือลบ
- Explorer อัปเดตไฟล์ที่สร้าง ลบ หรือเปลี่ยนชื่ออัตโนมัติ
- ตัวติดตั้งและตัวถอนการติดตั้งใช้ภาพแบรนด์ CodexDesk
- หน้าต่างอัปเดตแสดงเวอร์ชัน ความคืบหน้า และรอการยืนยันก่อนติดตั้ง
- จัดการอัปเดตและเปิดตัวถอนการติดตั้งได้จากภายในแอป
- ถอนการติดตั้งโดยเลือกได้ว่าจะเก็บหรือลบประวัติและการตั้งค่า
- Plugin Manager รองรับ MCP แบบ HTTP, STDIO และ OAuth
- ติดตั้ง GitHub, Canva และ Google Drive MCP ได้จากรายการด่วน
- รองรับคำสั่ง Slash Command ภายในช่องแชท
- คัดลอกข้อความหรือทั้งแชท ย้อนกลับไฟล์ก่อนงานล่าสุด และออกจากระบบได้จาก UI
- หน้า Settings ตั้งค่าธีม การส่งข้อความ การแจ้งเตือน สิทธิ์ และ Personalization ได้ในแอป
- เลือกภาษา English หรือไทยได้ โดยค่าเริ่มต้นเป็น English
- Codex ตรวจภาษาของข้อความล่าสุดและตอบด้วยภาษาเดียวกันอัตโนมัติ
- รองรับ Discord Rich Presence พร้อมสถานะงานและตัวเลือกซ่อนชื่อโปรเจกต์
- กดปิดหน้าต่างเพื่อซ่อนลง System Tray และเลือก Exit จากไอคอน Tray เพื่อปิดจริง
- เลือก GPT-5.6 Sol, Terra, Luna หรือค่าเริ่มต้นของบัญชี พร้อมระดับการคิด Low ถึง Extra high
- เลือกค้นเว็บแบบ Cached, Live หรือปิดได้ โดยเขียนค่าลง Codex config จริง
- รองรับคำแนะนำส่วนตัว บุคลิกการตอบ และระบบความทรงจำของ Codex
- อ่านนโยบายความเป็นส่วนตัวและคู่มือการจัดการข้อมูลของ OpenAI จากในแอป
- ใช้งานได้โดยไม่ต้องเปิดโฟลเดอร์ แอปจะสร้าง `Documents\\CodexDesk Workspace` อัตโนมัติ
- Git diff
- จำกัดการอ่านและเขียนไฟล์ในโปรเจกต์ที่เลือก
